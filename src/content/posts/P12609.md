### P12609 [CCC 2025 Junior] Roller Coaster Ride 题解
[题目传送门](https://www.luogu.com.cn/problem/P12609)

## 思路
简单语法题。

过山车的每节车厢可容纳一定数量的乘客，且每班过山车的所有车厢都会满载。计算下一班过山车总共能容纳的乘客数，即 $C \times P$，然后判断队伍中的位置是否小于或等于这个总数即可。
## Code
```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
int n,c,p;
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>n>>c>>p;
	cout<<(n<=c*p ? "yes" : "no");
	return 0;
}
```
