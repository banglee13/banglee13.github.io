## 思路

利用斐波那契数列的一个性质：所有满足 $k \mid F(n)$ 的下标 $n$，恰好是某个固定值 $m$ 的倍数，即 $k\mid F(n) \iff m\mid n$。这个 $m$ 就是第一个能被 $k$ 整除的斐波那契数的下标。

所以我们只需要暴力递推 $F(i) \bmod k$，直到第一次出现 $0$，记下此时的下标 $m$。这样第 $n$ 个能被 $k$ 整除的斐波那契数的下标就是 $nm$。

由于 Pisano 周期的性质，$m$ 的数量级是 $O(k)$，不会 TLE。

注意当 $k=1$ 时，每个斐波那契数都能被 $1$ 整除，第 $n$ 个下标就是 $n$ 本身。

## Code

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
const int mod=1e9+7;
int T;
signed main() {
    ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
    cin>>T;
    while (T--) {
        int n,k;
        cin>>n>>k;
        if (k==1) {
            cout<<n%mod<<'\n';
            continue;
        }
        int a=1,b=1,c=2,i=3;
        int ans=0;
        while (true) {
            c=(a+b)%k,a=b,b=c;
            if (c==0) {
                ans=i;
                break;
            }
            i++;
        }
        cout<<n%mod*ans%mod<<'\n';
    }
    return 0;
}
```
