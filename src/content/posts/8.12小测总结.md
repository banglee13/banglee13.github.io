## T1 勇士
贪心+数学。

分类讨论，先考虑特殊情况。

如果有一种武器能直接把怪物杀掉，那就没必要考虑其他武器了，答案为 $1$。

如果所有武器的净减少量都不大于 $0$（即 $\max(d_i - h_i) \le 0$），则无法击败怪物。

特殊情况考虑完了，再来考虑一般情况。

先使用净减少量最大的武器，直到怪物头数小于所有武器中最大造成的伤害，那么就可以用这种武器直接击败。

设最大净减少量为 $maxl$，最大单次伤害为 $maxd$，那么最终需要 $\left \lceil \frac{x-maxd}{maxl} \right\rceil + 1$ 次。

```cpp line-numbers
#include<bits/stdc++.h>
using namespace std;
#define int long long
int n,x,maxd,maxl=INT_MIN,d[105],h[105];
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>n>>x;
	for (int i=1;i<=n;i++)
		cin>>d[i]>>h[i],maxd=max(maxd,d[i]),maxl=max(maxl,d[i]-h[i]);
	if (maxd>=x) cout<<1;
	else if (maxl<=0) cout<<-1;
	else cout<<((x-maxd)+maxl-1)/maxl+1;
	return 0;
}
```

### 反思
赛时脑抽计算一般情况时用了模拟的方法，数据水居然过了，要多想优化的方法。

## T2 星星点灯
将问题转化为最小生成树问题：
- 将每颗星星看作图中的节点。
- 直接点亮星星的花费为 $m$，可以看作一个虚拟节点到该星星的边权为 $m$。
- 星星之间点亮的花费为 $F_{i,j}$。

用 Kruskal 求最小生成树即可。

时间复杂度为 $O(n^2 \log n)$。

```cpp line-numbers
#include<bits/stdc++.h>
using namespace std;
#define int long long
struct edge {
    int u,v,w;
    bool operator < (const edge &x) const {
        return w < x.w;
    }
};
int m,n,ans=0,fa[2005];
vector<edge> e;
int find(int x) {
    if (x==fa[x]) return x;
    return fa[x]=find(fa[x]);
}
signed main() {
    ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
    cin>>m>>n;
    // 初始化并查集
    for (int i=0;i<=n;i++)
        fa[i]=i;
    // 加虚拟节点
    for (int i=1;i<=n;i++)
        e.push_back({0,i,m});
    // 加边
    for (int i=1,w;i<=n;i++)
        for (int j=1;j<=n;j++)
            cin>>w,e.push_back({i,j,w});
    // Kruskal
    sort(e.begin(),e.end());
    for (auto ed:e) {
        int u=find(ed.u), v=find(ed.v);
        if (u!=v) fa[u]=v,ans+=ed.w;
    }
    cout<<ans;
    return 0;
}
```

## T3 蛋糕
考虑二进制位贪心。

统计每个二进制位上蛋糕的数量（$d_i$ 表示大小为 $2^i$ 的蛋糕数量），从低位到高位遍历，如果当前位需要 $1$ 但没有蛋糕，则向上寻找最近的更大蛋糕进行切割即可。

时间复杂度为 $O(m+\log^2 n)$。

```cpp line-numbers
#include<bits/stdc++.h>
#define int long long
using namespace std;
int n,m,sum,p,p1,p2,a[100005],s[100005],d[100005];
signed main(){
    ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
    cin>>n>>m;
    for (int i=1;i<=m;i++) {
        cin>>a[i];
        sum+=a[i];
    }
    if (sum<n) {
        cout<<-1;
        return 0;
    }
    // n转二进制
    while (n) {
        s[p++]=n%2;
        n/=2;
    }
    p1=p;
    // 统计每个二进制位的蛋糕数量
    sort(a+1,a+1+m);
    for (int i=1;i<=m;i++) {
        p=0;
        int t=a[i];
        while (t) {
            d[p++]+=t%2;
            t/=2;
        }
        p2=max(p2,p);
    }
    sum=0; // 切割次数
    for (int i=0;i<p1;i++) {
        if (s[i]==1) {
            if (d[i]>0) d[i]--;
            else {
                // 向上找蛋糕切割
                int pos=0;
                for (int j=i+1;j<=p2;j++) {
                    if (d[j]>0) {
                        d[j]--;
                        pos=j;
                        break;
                    }
                }
                // 切割产生的小蛋糕
                for (int j=i;j<pos;j++) {
                    d[j]++;
                    sum++;
                }
            }
        }
        // 向高位进位（两个2^i合成一个2^(i+1)）
        if (d[i]>0) {
            d[i+1]+=d[i]/2;
            d[i]%=2;
        }
    }
    cout<<sum;
    return 0;
}
```

## T4 翘课计划
~~真正的 dp~~。背包DP+预处理。

想，某一天的课程安排是：

$$
1 0 1 0 1
$$

你会优先翘哪一天的课？

如果选中间的那一节课：

$$
1 0 {\color{red}1} 0 1
$$

那么待在教学楼的时间依然为 $5-1+1=5$。

如果选首尾任意一节课：

$$
{\color{red}1} 0 1 0 {\color{red}1}
$$

那么待在教学楼的时间为 $5-3+1=3 \: 或 \: 3-1+1=3$。

显然优先翘首尾的课是最优方案。

再想，现在有两天，分别是：
$$
1 0 0 1
$$
$$
1 0 1 0
$$
你会优先翘哪一天的课？

第一天待在教学楼的时间为 $4-1+1=4$，第二天待在教学楼的时间为 $3-1+1=3$，显然，翘第一天是最优方案。

那么，我们可以记录每一天的 $b-a+1$，按照 $b-a+1$ 从大到小排序，优先翘待在教学楼最大时间的那一天的课。

显然会 T 飞。考虑优化。

对每一天预处理，对于翘掉 $j$ 节课的情况，计算该天的最短停留时间 $b_{i,j}$。

$f_j$ 表示总共翘 $j$ 节课时的最小总时间。

那么状态转移方程就可以轻松推出来：
$$
f_j = \min(f_j,f_k + b_{i,j-k})
$$

```cpp line-numbers
#include<bits/stdc++.h>
using namespace std;
#define int long long
int n,m,q,ans=INT_MAX,a[505][505],b[505][505],f[505];
signed main() {
    ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
    cin>>n>>m>>q;
    memset(b,0x3f,sizeof(b));
    memset(f,0x3f,sizeof(f));
    for (int i=1;i<=n;i++) {
        int cnt=0;
        for (int j=1;j<=m;j++)
            cin>>a[i][j],cnt+=a[i][j];
        b[i][cnt]=0; // 不翘任何课
        // 枚举所有可能的连续时间段
        for (int j=1;j<=m;j++) {
            int cur=0;
            for (int k=j;k<=m;k++) {
                cur+=a[i][k];
                b[i][cnt-cur]=min(b[i][cnt-cur],k-j+1);
            }
        }
    }
    f[0]=0;
	for (int i=1;i<=n;i++)
		for (int j=q;j>=0;j--) {
			f[j]+=b[i][0];
			for (int k=j-1;k>=0;k--)
				f[j]=min(f[j],f[k]+b[i][j-k]);
		}
    for (int i=0;i<=q;i++)
        ans=min(ans,f[i]);
    cout<<ans;
    return 0;
}
```
