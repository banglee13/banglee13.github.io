### P14064 [PO Final 2022] 卡牌 / Kortlek 题解

## 思路
先将 $a,b$ 排序，当 $a,b$ 都按相同顺序排序后配对，就能得到最小的绝对差值总和。

观察到 $M=N$ 或 $M=N+1$，那么我们可以分类讨论。

### 当 $M=N$ 时
Simon 必须用完所有的牌。

此时最优策略就是将排序后的 $a$ 和 $b$ 按位置一一对应，答案就是 $\sum_{i=1}^N |a_i-b_i|$。

### 当 $M=N+1$ 时
Simon 有多余的一张牌可以不用。

最直接的方法就是枚举 Simon 不用哪张牌，但时间复杂度为 $O(N^2)$，显然会 TLE。

因此考虑优化。观察到 Simon 不用第 $k(1 \le k \le N+1)$ 张牌时，前 $k-1$ 张 Simon 的牌与 Nicole 的前 $k-1$ 张牌配对，Simon 的第 $k+1$ 到 $N+1$ 张牌与 Nicole 的第 $k$ 到 $N$ 张牌配对。

因此，我们可以预处理两个数组 $pre$ 和 $suf$，分别表示 Simon 使用前 $i$ 张牌与 Nicole 前 $i$ 张牌配对的总得分和 Simon 使用后 $N-i+1$ 张牌（从第 $i+1$ 张开始）与 Nicole 后 $N-i+1$ 张牌（从第 $i$ 张开始）配对的总得分。

然后枚举跳过的位置 $k$，答案取最小值即可，此时时间复杂度就降到了 $O(N)$。

::::warning[警告]
因为 $N \le 2 \times 10^5$ 且 $a_i, b_i \le 10^9$，最大可能得分为 $2 \times 10^5 \times 10^9 = 2 \times 10^{14}$，需要开 `long long`。
::::

## Code
```cpp line-numbers
#include<bits/stdc++.h>
using namespace std;
#define int long long
int n,m,ans,a[200005],b[200005],pre[200005],suf[200005];
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>n>>m;
	for (int i=1;i<=n;i++)
		cin>>a[i];
	for (int i=1;i<=m;i++)
		cin>>b[i];
	sort(a+1,a+1+n);
	sort(b+1,b+1+m);
	if (m==n)
		for (int i=1;i<=n;i++)
			ans+=abs(a[i]-b[i]);
	else {
		for (int i=1;i<=n;i++)
			pre[i]=pre[i-1]+abs(a[i]-b[i]);
		for (int i=n;i>=1;i--)
			suf[i]=suf[i+1]+abs(a[i]-b[i + 1]);
		ans=LLONG_MAX;
		for (int i=0;i<=n;i++)
			ans=min(ans,pre[i]+suf[i+1]);
	}
	cout<<ans;
	return 0;
}
```
