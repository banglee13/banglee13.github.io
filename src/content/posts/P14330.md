### P14330 [JOI2021 预选赛 R2] 往返滑道 / Round Sugoroku 题解

[题目传送门](https://www.luogu.com.cn/problem/P14330)

## 思路

首先考虑直接模拟，但直接模拟会因为 $N \le 2 \times 10^5$ 且路径可能很长而 TLE。

因此需要跳过无效移动，直接跳转到下一个 `#` 或边界来优化。

注意到棋子只在遇到 `#` 或边界时改变方向，且每个 `#` 只会被清除一次，之后变为 `.`，不再影响方向。

因此，我们可以用一个 `set` 维护当前所有还没清除的 `#` 的位置。

每次根据当前方向，找到下一个会触发转向的位置。最后累加移动距离，更新位置和方向，并从集合中删除已清除的 `#` 即可。

:::info[时间复杂度]
时间复杂度为 $O(k \log k)$，其中 $k$ 是 `#` 的数量（最多 $N$）。每次清除一个 `#`，`set` 操作 $O(\log k)$。
:::

## Code

```cpp line-numbers
#include<bits/stdc++.h>
using namespace std;
#define int long long
int n,a,d=1,ans;  //d: 方向（1右，-1左）ans: 总时间
string s;
set<int> h; //存储所有 '#' 的位置
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>n>>a>>s;
	for (int i=1;i<=n;i++)
		if (s[i-1]=='#')  h.insert(i);
	int cur=a;  //当前棋子位置
	//模拟直到所有 '#' 被清除
	while (!h.empty()) {
		if (d==1) {  //当前向右移动
			auto it=h.lower_bound(cur);  //找到第一个 >=cur 的 '#' 位置
			if (it==h.end()) {
				//右侧已经没有 '#'，走到右边界 n+1
				ans+=n+1-cur;
				cur=n+1;
				d=-1;  //在边界 'x' 处反转方向
			}
			else {
				// 走到最近的 '#' 并清除它
				ans+=(*it)-cur;
				cur=*it;
				h.erase(it);  //清除该 '#'（变为 '.'）
				d=-1;       //在 '#' 处反转方向
			}
		}
		else {  //当前向左移动
			auto it=h.upper_bound(cur);  //找到第一个 >cur 的 '#' 位置
			if (it==h.begin()) {
				//左侧已经没有 '#'，走到左边界 0
				ans+=cur-0;
				cur=0;
				d=1;  //在边界 'x' 处反转方向
			} else {
				it--;  //it 指向最后一个 <=cur 的 '#'（即左侧最近的）
				//走到最近的 '#' 并清除它
				ans+=cur-(*it);
				cur=*it;
				h.erase(it);  //清除该 '#'
				d=1;        //在 '#' 处反转方向
			}
		}
	}
	cout<<ans;
	return 0;
}
```
