## 完善程序

求：

前 $ N $ 个小写字母中取 $ M $ 个的所有排列。按照字典序从小到大输出。$ 0< M \le N <6 $。

按照提示填空即可。

```cpp
#include<bits/stdc++.h>

using namespace std;
int N, M;
int used[10];
int ans[10];

void print() {
    for (int j = 0; j < M; j++)
        cout << char(ans[j] + 'a');
    cout << endl;
}

void perm(int i) {
    if (i == M) {  //边界条件
        print();
        return;
    }
    for (int j = 0; j < N; j++) //试取字母
        if (used[j] == 0) { //字母还没有使用
            used[j] = 1;    //使用第j字母
            ans[i] = j;   //第i位置取第j个字母
            perm(i + 1);    //递归第i+1个位置
            used[j] = 0;    //递归回来时，还回字母
        }
}

int main() {
    cin >> N >> M;
    perm(0);
    return 0;
}
```

## T2

按照字典序**从大到小**输出。

改存答案方向即可。


## T3

相邻的位置上字母**不能**是相邻字母。

特判一下就行。

```
#include<bits/stdc++.h>
using namespace std;
#define int long long
int n,m,ans[10];
bool vis[10];
void print() {
    for (int i=0;i<m;i++)
        cout<<char(ans[i]+'a');
    cout<<'\n';
}
void dfs(int p) {
    if (p==m) {
        print();
        return;
    }
    for (int i=0;i<n;i++)
        if (!vis[i]) {
            if (p>0 && abs(ans[p-1]-i)==1) continue;
            vis[i]=true,ans[p]=i;
            dfs(p+1);
            vis[i]=false;
        }
}
signed main() {
    ios::sync_with_stdio(!(cin.tie(0) && cout.tie(0)));
    cin>>n>>m;
    dfs(0);
    return 0;
}
```

## T4

从前 $ N $ 个正整数中取 $ M $ 个的所有排列，但相邻位置上数字要求**互质**。按照字典序从小到大输出。

判互质就行了。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
int n,m,ans[10];
bool vis[10];
void print() {
    for (int i=0;i<m;i++)
        cout<<ans[i]<<" ";
    cout<<'\n';
}
void dfs(int p) {
    if (p==m) {
        print();
        return;
    }
    for (int i=1;i<=n;i++)
        if (!vis[i]) {
            if (p>0 && __gcd(ans[p-1],i)!=1) continue;
            vis[i]=true,ans[p]=i;
            dfs(p+1);
            vis[i]=false;
        }
}
signed main() {
    ios::sync_with_stdio(!(cin.tie(0) && cout.tie(0)));
    cin>>n>>m;
    dfs(0);
    return 0;
}
```
