# 鸽巢原理的扩展

## 推论

证明：

1. $ A $ 个物品放入 $ n $ 个盒子中，$ A $ 不是 $ n $ 的倍数，则至少有一个盒子中有 $ \lfloor \dfrac{A}{n} \rfloor +1 $ 个物品。
2. 或者说：若将 $ n \times r + 1 $ 个物品放入 $ n $ 个盒子中，则至少有一个盒子中有 $ r+1 $ 个物品。

考虑反证法。

### 对于命题 1 的证明

假设结论不成立，即每个盒子里放的物品个数都小于等于 $ \lfloor \dfrac{A}{n} \rfloor $ 个。

那么 $ n $ 个盒子中物品的总数量最多为 $ n \times \lfloor \dfrac{A}{n} \rfloor $ 个。

因为 $ A $ 不是 $ n $ 的倍数，所以$ \lfloor \dfrac{A}{n} \rfloor < \dfrac{A}{n} $，可以变成 $ n \times \lfloor \dfrac{A}{n} \rfloor < n \times \dfrac{A}{n} = A $。

这意味着 $ n $ 个盒子中物品的总数小于实际有的物品总数 $ A $，产生了矛盾。

证毕。

### 对于命题 2 的证明

这里 $ A = nr +1 $，那么 $ \dfrac{A}{n} = \dfrac{nr +1}{n} = r+ \dfrac{1}{n} $，所以 $ \lfloor \dfrac{A}{n} \rfloor = r (\text{因为} \dfrac{1}{n} < 1，\text{取整后舍去}) $。

假设结论不成立，即每个盒子里放的物品个数都小于等于 $ r $ 个，那么 $ n $ 个盒子中物品的总数最多为 $ nr $ 个。

但实际有 $ nr +1 $ 个物品，所以 $ nr < nr+1 $，意味着盒子中物品的总数小于实际的物品总数，产生了矛盾。

证毕。

## 例 1

设有大小两只圆盘，每个都划分成大小相等的 $ 200 $ 个小扇形，在大盘上任选 $ 100 $ 个小扇形漆成黑色，其余的 $ 100 $ 个小扇形漆成白色，而将小盘上的 $ 200 $ 个小扇形任意漆成黑色或白色。现将大小两个圆盘的中心重合，转动小盘使小盘上的每个扇形含在大盘上的小扇形之内。

**证明**：有一个位置使小盘上至少有 $ 100 $ 个小扇形同大盘上相应的小扇形同色。

反证法。

假设结论不成立，即不存在一个旋转位置使得小盘上有至少 $ 100 $ 个小扇形与大盘上相应的小扇形同色。

那么小盘上同色的扇形数量最多为 $ 99 $ 个，即 $ x \le 99 $。

因此，小盘上不同色的扇形数量至少为 $ 200 - x \ge 200 - 99 = 101 $。

将小盘上的 $ 200 $ 个扇形划分为四类：

1. 同色黑色 - $ b $。
2. 同色白色 - $ w $。
3. 不同色黑色 - $ b' $。
4. 不同色白色 - $ w' $。

根据大盘的扇形颜色分布，得知大盘上有 $ 100 $ 个扇形是黑色，$ 100 $ 个扇形是白色。因此小盘上与大盘不同色的扇形中，最多只能有 $ 100 $ 个是不同色扇形，否则会违反大盘的扇形数目限制。

然而我们却得到了 $ b' + w' \ge 101 $，意味着小盘上不同色的扇形数量超过大盘的限制，产生了矛盾。

证毕。

## T1

找规律。

对于 $ 1 $  位数，只有 $ 1 $ 个 $ 8 $。

对于 $ 2 $ 位数，考虑首位不能为 $ 0 $，其余位置可以自由组成，有 $ 8,18,28,38,48,58,68,78,88,98,80,81,82,83,84,85,86,87,89 $，共 $ 20 $ 个。

对于 $ N $ 位数，发现：如果 $ 8 $ 出现在第一位，后面的位数可以是 $ 0 $ 到 $ 9 $，这样可以组合出很多数字。

答案就是 $ n \times 10^{n-1} $。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
int n;
signed main() {
    cin>>n;
    cout<<(int)(n*pow(10,n-1));
    return 0;
}
```

## T4

证明：每次给两个整数 $ n(100 \le n \le 1000000),m(2 \le m \le n) $，在 $ 1 \to n $ 个数中，随机取 $ m $ 个数，问在这 $ m $ 个数中是否一定存在一个数是另一个数的倍数，是则回答 `YES`，否则 `NO`。

考虑在区间 $ 1 $ 到 $ n $ 之间的数，可以将这些数进行分组，使得每个组中的数具有相似的特征。具体地，我们可以将每个数 $ k $ 分配到它的倍数类中。换句话说，可以用数的形式 $ 1,2,\dots,n $ 中的数来将它们分到不同的组中。

对于每一个正整数 $ k $（在范围 $ 1 $ 到 $ n $ 内），可以看作它的倍数类是 $ k,2k,3k,\dots $ 直到最大不超过 $ n $ 的数。对于给定的 $ n $ 和  $ m $，可以将这些数分配到以下的类别中：

* 第一组：$ {1} $。
* 第二组：$ {2,4,6,\dots} $。
* 第三组：$ {3,6,9,\dots} $。
* 依此类推，直到 $ k $。

再计算这些组的数量。

假设这 $ m $ 个数选自 $ 1 $ 到 $ n $，最大能有   $ \log_2 n $ 个不相同的组，因为在每个组里，最大可取的数的倍数最大是 $ n $。

根据鸽巢原理，如果选择的 $ m $ 个数不同，而这些数可以归类到极少数的类别中，必然会有至少一个类包含多个数。因此，不同数在这些组中必定会导致至少一个组中存在数是另一个数的倍数。

因此，不论 $ n $ 和 $ m $ 的值如何，只要 $ m > \log_2 n $，就可以肯定地说：在这 $ m $ 个数中必定存在一对数，其中一个数是另一个数的倍数。

证毕。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
int T;
signed main() {
    cin>>T;
    while (T--) {
        int n,m;
        cin>>n>>m;
        if (n%2==0) n/=2;
        else n=n/2+1;
        if (m>n) cout<<"YES\n";
        else cout<<"NO\n";
    }
    return 0;
}
```

## 作业 1

证明：某次会议 $ n $ 位代表参加，至少有两个人认识的人数相等。注意认识是相互的。

假设有 $ n $ 位代表参加会议。每位代表最多可以认识的其他代表人数为  $ n-1 $（因为每位代表不能认识自己）。因此，认识的人的数量可能为 $ 0,1,2,\dots,n-1 $，共 $ n $ 种可能的认识人数。

在这 $ n $ 位代表中，若每位代表的认识人数都不相等，那么会有 $ n $ 位代表的认识人数都是从 $  0 $ 到 $ n-1 $ 的不同值。在这种情况下，假设有一位代表认识 $ 0 $ 个人（不认识其他人），那么就无法存在认识 $ n-1 $ 个人的代表（因为如果一个人要认识所有其他人，他也必须认识包含。因此，至少有一人最多只能认识 $ n-2 $ 个人。）

说明实际可取的认识人数仅为 $ 0,1,2,\dots,n-2 $，这总共只有 $ n-1 $ 种不同的可能。而有 $ n $ 位代表。因此至少有两位代表的认识人数必须相同。

证毕。

## 作业 2

证明：任给 $ 5 $ 个整数，证明其中必存在 $ 3 $ 个数的和被 $ 3 $ 除尽。

首先，考虑每个整数在模 $ 3 $ 下的余数。任意一个整数模 $ 3 $ 的结果只可能是 $ 0,1 $ 或 $ 2 $。也就是说，每个整数可以被分为三类：

* 余数为 $ 0 $;
* 余数为 $ 1 $;
* 余数为 $ 2 $;

由于有 $ 5 $ 个数，而在模 $ 3 $ 下只有 $ 3 $ 个可能的余数，因此根据抽屉原理，至少有两个数会在同一个余数中。

分类讨论：

1. ​如果有至少 $ 3 $ 个数的余数为 $ 0 $：那么这 $ 3 $ 个数的和显然是 $ 0 $，能够被 $ 3 $ 整除。
2. ​如果有 $ 2 $ 个数的余数为 $ 0 $​：假设这两个数是 $ a_1 $ 和 $ a_2 $。现在，考虑其余的 $ 3 $ 个数。余数可以是 $ 0,1,2 $ 的组合。由于已经有 $ 2 $ 个余数为 $ 0 $ ，所以在剩下的 $ 3 $ 个数中，必然有至少 $ 1 $ 个数的余数是 $ 1 $ 或 $ 2 $。
   
   * 如果这 $ 3 $ 个数中有一个数的余数为 $ 1 $，那么可以选择这两个余数为 $ 0 $ 的数和这个余数为 $ 1 $ 的数，其和的余数为 $ 0 + 0 + 1 \equiv 1 \pmod 3$。
   * 如果这 $ 3 $ 个数中有一个数的余数为 $ 2 $，那么可以选择这两个余数为 $ 0 $ 的数和这个余数为 $ 2 $ 的数，其和的余数为 $ 0 + 0 + 2 \equiv 2 \pmod 3 $。
     在这两种情况下，选择余数为 $ 1 $ 或 $ 2 $ 的数和任意两个余数为 $ 0 $ 的数，最终仍然无法得到和为 $ 0 $（能够被 $ 3 $ 整除）。但是，另外两个数的组合可以形成。
3. ​如果 $ 3 $ 个数的余数为 $ 1 $ 和 $ 2 $ 的组合：假设有 $ 2 $ 个余数为 $ 1 $ 的数和 $ 2 $ 个余数为 $ 2 $ 的数。无论如何，两组数的和总会组合成至少一个能被 $ 3 $ 整除。

证毕。
