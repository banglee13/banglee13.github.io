妙妙题。

## 思路

我们考虑一下什么情况贪心策略会错误。

::::error[错误的想法]
首先有一个很直接的想法，将 $a$ 数组从大到小排序后，存在任意一个满足 $\frac{a_i}{b_i}<\frac{a_j}{b_j} (1 \le i \le k, k+1 \le j \le n)$ 此时这个贪心策略就是错误的。

看起来很对……吗？

我们要求的是一个整体平均值，所以这样是错的。举个例子：

设 $n=3, k=2, a=[100,20,8], b=[1,2,1]$。

按照贪心策略，这个答案应该是 $\frac{1000+20}{1+2}=340$。

再按照我们的思路，我们会发现，前 $k$ 个物品中的每一个的 $\frac{a_i}{b_i}$ 都比外面的物品 3 高。

但如果我们把物品 2 换成物品 3，新的答案为 $\frac{1000+8}{1+1}=504$。
::::

那么什么时候替换会让答案变优呢？

::::success[正确策略]
我们设当前贪心得到的答案为 $x=\frac{V}{W}$。

把前 $k$ 个物品 $i(b_i=2)$ 换成外面的物品 $j(b_j=1)$，那么替换之后的 $x_2=\frac{V-(a_i-a_j)}{W-1}$，这个方案更优的充要条件就是 $x_2>x$。

整理一下得到：
$$
V-(a_i-a_j)>x(W-1)
$$

又因为 $x \cdot W=V$，代入得：

$$
a_i-a_j<x
$$

也就是说，贪心策略是全局最优解当且仅当 $a_i-a_j \ge x$。
::::

我们要让所有的 $a_i-a_j \ge x$ 都成立，显然我们只需要找到最小的 $a_i$ 和最大的 $a_j$ 做比较即可。

要让 $a_i$ 尽量小，那么我们就要选前 $k$ 个里**最后一个**取 $b=2$ 的物品 $i$；要让 $a_j$ 尽量大，那么我们就要选后 $n-k$ 个里**第一个**取 $b=1$ 的物品 $j$。

我们设前 $k$ 个数里有 $c$ 个物品的 $b=2$，其他的 $b=1$。

那么 $x=\dfrac{\sum_{i=1}^k a_i}{(k-c) \times 1+c \times 2=k+c}$。

好了此时我们有一个很直接的想法，直接枚举 $i,j$ 不就完了，但是因为此时的 $c$ 没有确定，所以 $x$ 也不确定，枚举完 $i,j$ 之后还需要用一层循环去累加满足不等式的 $c$ 的组合数，所以这样做的时间复杂度是 $O(n^3)$，显然会 TLE。

所以我们考虑枚举 $c$，此时 $x$ 就固定了。既然 $x$ 都是定值了，那么 $a_i-a_j \ge x$ 就具有单调性，这样 $i$ 和 $j$ 就可以使用双指针 $O(n)$ 地扫过去。

我们分类讨论一下 $c$：
1. 当 $c=0$ 时，此时前 $k$ 个 $b$ 全为 $1$，后 $n-k$ 个 $b$ 任意选，贡献为 $2^{n-k}$；
2. 当 $c \ge 1$ 时，且后半段全为 $2$。此时前 $k$ 个数至少选一个 $2$ 的方案数为 $2^k-1$，后 $n-k$ 个数全为 $2$ 只有 $1$ 种选法，贡献为 $2^k-1$。
3. 当 $c \ge 1$ 时，且后 $n-k$ 个数存在 $1$。此时前半部分在 $i$ 之前选 $c-1$ 个 $2$，方案数为 $\binom{i-1}{c-1}$；后半部分合法的 $j$ 是一个连续的后缀 $[j_{\min},n]$，每个合法位置后面随便选，方案数为 $2^{n-j_{\min}+1}-1$。根据乘法原理，总贡献为 $\binom{i-1}{c-1} \times (2^{n-j_{\min}+1}-1)$。

来解释一下为什么后半段的方案数为 $2^{n-j_{\min}+1}-1$。

::::info[解释]
把后半段 $k+1 \sim n$ 分成两截：

$$
\underbrace{[2, 2, \dots, 2]}_{k+1 \sim j_{\min}-1} \underbrace{[?, ?, \dots, ?]}_{j_{\min} \sim n}
$$

对于前面部分（$k+1 \sim j_{\min}-1$），因为第一个 $1$ 最早也要在 $j_{\min}$ 才能出现，所以这里面必须全部填 $2$，只有 $1$ 种填法。

对于后面部分（$j_{\min} \sim n$），每个数都可以填 $1$ 或 $2$，本来共有 $2^{n-j_{\min}+1}$ 种填法。但是如果这一段全部填成了 $2$，那就代表后半段一个 $1$ 都没有了，会和前面的第二种分类讨论重复计算，把这一种情况减去即可。

当然你也可以用等比数列求和计算出来。
::::

## Code

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
const int maxn=2000;
const int mod=998244353;
struct node {
    int a,id;
}a[maxn+5];
bool cmp(node x,node y) {
    if (x.a!=y.a) return x.a>y.a;
    return x.id<y.id;
}
int n,k,pw[maxn+5],C[maxn+5][maxn+5];
void init() {
    pw[0]=1;
    for (int i=1;i<=maxn;i++)
        pw[i]=pw[i-1]*2%mod;
    for (int i=0;i<=maxn;i++) {
        C[i][0]=1;
        for (int j=1;j<=i;j++)
            C[i][j]=(C[i-1][j-1]+C[i-1][j])%mod;
    }
}
void solve() {
    cin>>n>>k;
    for (int i=1;i<=n;i++)
        cin>>a[i].a,a[i].id=i;
    sort(a+1,a+1+n,cmp);
    int suma=0;
    for (int i=1;i<=k;i++)
        suma+=a[i].a;
    int ans=pw[n-k]; // c=0
    ans=(ans+pw[k]-1+mod)%mod; // c>=1 且后 n-k 个 b 全是 2
    for (int c=1;c<=k;c++) {
        double x=suma*1.0/(k+c);
        int j=k+1;
        for (int i=c;i<=k;i++) {
            while (j<=n && (a[i].a-a[j].a)<x)
                j++;
            if (j<=n) ans=(ans+C[i-1][c-1]*((pw[n-j+1]-1+mod)%mod)%mod+mod)%mod;
        }
    }
    cout<<ans<<'\n';
}
signed main() {
    ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
    // freopen("beyond.in","r",stdin);
    // freopen("beyond.out","w",stdout);
    init();
    int T;
    cin>>T;
    while (T--)
        solve();
    return 0;
}
```
