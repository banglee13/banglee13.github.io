# 字符串哈希
## 定义
Hash 的核心思想在于，将输入映射到一个值域较小、可以方便比较的范围。

## 性质
具体来说，哈希函数最重要的性质可以概括为下面两条：

1. 在 Hash 函数值不一样的时候，两个字符串一定不一样；

2. 在 Hash 函数值一样的时候，两个字符串不一定一样（大概率一样）。

如果 Hash 函数值一样但原字符串不一样的现象，就称为哈希碰撞。

## 常见哈希
通常采用多项式 Hash 的方法。

计算方法为 $hash(s) = \sum^l_{i=1} s_i \times b^{l-i} \pmod M$。

但更多人使用的计算方法为 $hash(s) = \sum^l_{i=1} s_i \times b^{i-1} \pmod M$。

容易发现，上面的公式计算出的哈希值必然有 $hash(s) \in [0,M)$，也就是说，只有 $M$ 种不同的哈希值，这时候，可能出现**哈希碰撞**，也就是两个不同字符串的哈希值相同。

显然，$M$ 越大，生成的不同的哈希值的数量也就越多，哈希碰撞的概率也越小。

当然，我们也可以使用**自然溢出**，用 `unsigned long long` 存储哈希值，使哈希值自然溢出，相当于对 `unsigned long long` 的上界进行取模。

自然溢出的写法很好写，但缺点是容易被卡 ~~，在 CF 写自然溢出给你卡飞~~。

这时候，我们可以使用双哈希，使被卡的概率大大降低。

双哈希，顾名思义，用两个不同的 $b$ 和 $M$ 计算双哈希，再用一个 pair 存储即可。

## 模板

```cpp
const int b=131,mod=1e9+7;
```

### T2 前缀和后缀
对于每一个字符串 $S$，$h$ 记录前缀的哈希值。

那么枚举到长度为 $i$ 的子串时，前缀的哈希值为 $h_i$，后缀的哈希值为 $h_n - h_i \times p_i$，将这两个值一比较，如果相等，说明前缀和后缀相等，输出长度即可。

```cpp line-numbers
#include<bits/stdc++.h>
using namespace std;
#define int long long
const int P=131;
int n,m,h[1000005],p[1000005];
char s[1000005];
void init() {
	p[0]=1;
	for (int i=1;i<=n;i++)
		p[i]=p[i-1]*P,h[i]=h[i-1]*P+s[i]-'a'+1;
}
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	while (cin>>(s+1)) {
        n=strlen(s+1);
		init();
		for (int i=1;i<=n;i++) {
			int a=h[i],b=h[n]-h[n-i]*p[i];
			if (a==b) cout<<i<<" ";
		}
		cout<<'\n';
	}
	return 0;
}
```

### T3 字符串匹配
设 $l_1$ 是字符串 $s_1$ 的长度。

枚举字符串 $s_2$ 中子串的起点 $i$，那么当前子串的终点为 $i+l_1-1$，判断当前子串的哈希值是否与 $s_1$ 的哈希值相等即可。

```cpp line-numbers
#include<bits/stdc++.h>
using namespace std;
#define int long long
const int P=131;
const int maxn=1e6+5;
int T,l1,l2,h1[maxn],p1[maxn],h2[maxn],p2[maxn];
char s1[maxn],s2[maxn];
void init() {
	p1[0]=1;
	for (int i=1;i<=l1;i++)
		p1[i]=p1[i-1]*P,h1[i]=h1[i-1]*P+s1[i]-'a'+1;
	p2[0]=1;
	for (int i=1;i<=l2;i++)
		p2[i]=p2[i-1]*P,h2[i]=h2[i-1]*P+s2[i]-'a'+1;
}
int gh1(int l,int r) {
	return h1[r]-h1[l-1]*p1[r-l+1];
}
int gh2(int l,int r) {
	return h2[r]-h2[l-1]*p2[r-l+1];
}
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>T;
	while(T--) {
		cin>>(s1+1)>>(s2+1);
		l1=strlen(s1+1),l2=strlen(s2+1);
		init();
		int tar=gh1(1,l1),ans=0;
		for (int i=1;i<=l2-l1+1;i++)
			if (gh2(i,i+l1-1)==tar) ans++;
		cout<<ans<<'\n';
	}
	return 0;
}
```

### T5 成双成对字符串
#### 前缀
对于每个位置 $i$，需要找到所有可能的前缀 $A$，使得：
$$
A = s[l \dots mid]
$$
其中 $l \le mid<i$，且 $A$ 的长度为偶数。

#### 后缀
对于每个位置 $i$，我们需要找到所有可能的后缀 $B$，使得：
$$
B = s[mid+1 \dots r]
$$
其中 $ i<mid+1 \leq r$，且 $B$ 的长度为偶数。

#### 匹配
对于每个位置 $i$，如果存在某个 $mid$ 满足：
$$
s[l \dots mid] = s[mid+1 \dots r]
$$
则说明 $s[l \dots r]$ 是一个成双成对子串。

那么我们枚举所有可能的前缀 $A$ 和后缀 $B$ 即可。

时间复杂度为 $O(len^2)$。

```cpp line-numbers
#include<bits/stdc++.h>
using namespace std;
#define int long long
const int P=131;
int len,ans,h[2005],p[2005],pre[2005],suf[2005];
char s[2005];
void init() {
	p[0]=1;
	for (int i=1;i<=len;i++)
		p[i]=p[i-1]*P,h[i]=h[i-1]*P+s[i]-'a'+1;
}
int gh(int l,int r) {
	return h[r]-h[l-1]*p[r-l+1];
}
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>(s+1),len=strlen(s+1);
	init();
	for (int i=2;i<=len;i++)
		for (int j=2;j<=i;j+=2) {
			int mid=i-j/2;
			if (gh(i-j+1,mid)==gh(mid+1,i)) pre[i]++;
		}
	for (int i=1;i<len;i++)
		for (int j=2;j<=len-i+1;j+=2) {
			int mid=i+j/2-1;
			if (gh(i,mid)==gh(mid+1,i+j-1)) suf[i]++;
		}
	for (int i=1;i<=len;i++)
		ans+=pre[i-1]*suf[i];
	cout<<ans;
	return 0;
}
```

### T6 Compress Words
首先考虑暴力，可以用 `substr` 或者双指针，最坏情况下时间复杂度会达到 $O(len^2)$。

所以考虑优化。因为涉及到字符串比较，很容易想到用哈希解决。

可以预处理第一个字符串的后缀哈希和第二个字符串的前缀哈希。然后从大到小枚举可能的重叠长度 $l$，检查后缀 $[tot-j+1,tot]$ 的哈希值是否等于当前单词的哈希值。

```cpp line-numbers
#include<bits/stdc++.h>
using namespace std;
#define int long long
const int maxn=1e6+5,P=131;
int n,len,tot,h[maxn],H[maxn],p[maxn];
char s[maxn],ans[maxn];
void init() {
	p[0]=1;
	for (int i=1;i<=maxn;i++)
		p[i]=p[i-1]*P;
}
int gh(int t,int r) {
	return H[r]-H[t-1]*p[r-t+1];
}
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	init();
	cin>>n;
	for (int i=1;i<=n;i++) {
		cin>>(s+1),len=strlen(s+1);
		for (int j=1;j<=len;j++)
			h[j]=h[j-1]*P+s[j];
		int t=0;
		for (int j=min(len,tot);j>=0;j--)
			if (h[j]==gh(tot-j+1,tot)) {
				t=j;
				break;
			}
		for (int j=t+1;j<=len;j++)
			ans[++tot]=s[j],H[tot]=H[tot-1]*P+s[j];
	}
	for (int i=1;i<=tot;i++)
		cout<<ans[i];
	return 0;
}
```

### T7 企鹅 QQ
首先考虑暴力，枚举所有的字符串对，逐位比较，时间复杂度为 $O(n^2L)$。

如果两个字符串只在第 $p$ 位不同，那么它们在去掉第 $p$ 位后的其余部分是完全相同的。

知道这一点，我们就可以枚举这个 $p$，计算去掉第 $p$ 位后的哈希值。

利用下标计数的思想，将这些哈希值统计起来。对于每个哈希值出现 $k$ 次，则可以组成 $C_k^2 = \frac{k(k-1)}{2}$ 对相似字符串。

累加这些答案即可。

```cpp lines=27-27 line-numbers
#include<bits/stdc++.h>
using namespace std;
#define int long long
const int P=131;
int n,l,S,ans,p[205],pre[30005][205],suf[30005][205];
char s[30005][205];
void init() {
	p[0]=1;
	for (int i=1;i<205;i++)
		p[i]=p[i-1]*P;
	for (int i=1;i<=n;i++) {
		for (int j=1;j<=l;j++)
			pre[i][j]=pre[i][j-1]*P+s[i][j];
		for (int j=l;j>=1;j--)
			suf[i][j]=suf[i][j+1]+s[i][j]*p[l-j];
	}
}
int gh(int i,int pos) {
	return pre[i][pos-1]*p[l-pos]+suf[i][pos+1];
}
signed main() {
	scanf("%lld%lld%lld",&n,&l,&S);
	for (int i=1;i<=n;i++)
		scanf("%s",s[i]+1);
	init();
	for (int p=1;p<=l;p++) {
		unordered_map<int,int> mp; //用传统map会超时，因此使用基于哈希表的unordered_map
		for (int i=1;i<=n;i++)
			mp[gh(i,p)]++;
		for (auto x:mp)
			ans+=x.second*(x.second-1)/2;
	}
	printf("%lld",ans);
	return 0;
}
```

### T8 OKR-A Horrible Poem
设子串长度为 $len=r-l+1$。

如果该子串有一个长度为 $d$ 的周期，那么必须满足：

- $ d \mid len $；
- 对于所有 $i \in [l, r - d]$，有 $s_i=s_{i+d}$。

可以用哈希来快速判断子串 $[l,r-d]$ 是否等于 $ [l+d,r]$，即：
$$
hash(l, r - d) = hash(l + d, r)
$$


> $最短周期长度=原始长度 \div 最大重复次数$

而最大重复次数一定是长度 $ len $ 的因数。

从 $len$ 开始，尝试不断除以质因数，看是能否构成周期。

对于每个质因数 $p$，尝试将 $ans$ 除以 $p$，只要结果仍是周期，最终剩下的就是答案。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
const int maxn=5e5+5,P=131;
int n,q,tot,pri[maxn],g[maxn],h[maxn],p[maxn];
bool vis[maxn];
char s[maxn];
void init1() {
	for (int i=2;i<=n;i++) {
		if (!vis[i]) pri[++tot]=i,g[i]=i;
		for (int j=1;j<=tot && pri[j]*i<=n;j++) {
			vis[pri[j]*i]=true,g[pri[j]*i]=pri[j];
			if (i%pri[j]==0) break;
		}
	}
}
void init2() {
	p[0]=1;
	for (int i=1;i<=n;i++)
		p[i]=p[i-1]*P,h[i]=h[i-1]*P+s[i]-'a'+1;
}
int gh(int l,int r) {
	return h[r]-h[l-1]*p[r-l+1];
}
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>n>>(s+1)>>q;
	init1();
	init2();
	while (q--) {
		int l,r,len,ans;
		cin>>l>>r;
		ans=len=r-l+1;
		if (gh(l+1,r)==gh(l,r-1)) {
			cout<<"1\n";
			continue;
		}
		while (len>1) {
			if (gh(l+ans/g[len],r)==gh(l,r-ans/g[len])) ans/=g[len];
			len/=g[len];
		}
		cout<<ans<<'\n';
	}
	return 0;
}
```

### T9 Kefa and Watch
注意到有区间修改和区间查询，于是想到可以用线段树做。

如何快速判断一个子串是否有周期 $d$？

根据定义，$s[l \dots r]$ 有周期 $d$，可以转化为 $s[l \dots r−d]=s[l+d \dots r]$。

如果一个长度为 $len$ 的区间全部是数字 $c$，那么它的哈希值是：
$$
hash = c(1 + P + P^2 + \cdots + P^{len−1})=c \times pre_{len−1}
$$

其中 $pre_i = 1 + P + P^2 + \dots + P^i$。

总体时间复杂度为 $O((m+k) \log n)$。

```cpp line-numbers
#include<bits/stdc++.h>
using namespace std;
#define int long long
#define lc 2*p
#define rc 2*p+1
const int maxn=1e5+5,P=131,mod=1e9+9;
struct node {
	int h,lzy,len;
} tree[maxn*4];
int n,m,k,pw[maxn],pre[maxn];
char s[maxn];
void init() {
	pw[0]=1,pre[0]=1;
	for (int i=1;i<=n;i++)
		pw[i]=pw[i-1]*P%mod,pre[i]=(pre[i-1]+pw[i])%mod;
}
int gh(int c,int len) {
	return c*pre[len-1]%mod;
}
void pushup(int p) {
	tree[p].h=(tree[lc].h*pw[tree[rc].len]%mod+tree[rc].h)%mod;
}
void pushdown(int p) {
	if (tree[p].lzy!=-1) {
		int c=tree[p].lzy;
		tree[lc].h=gh(c,tree[lc].len);
		tree[rc].h=gh(c,tree[rc].len);
		tree[lc].lzy=tree[rc].lzy=c;
		tree[p].lzy=-1;
	}
}
void build(int l,int r,int p) {
	tree[p].len=r-l+1;
	tree[p].lzy=-1;
	if (l==r) {
		tree[p].h=s[l]-'0';
		return;
	}
	int mid=(l+r)/2;
	build(l,mid,lc);
	build(mid+1,r,rc);
	pushup(p);
}
void update(int l,int r,int c,int s,int t,int p) {
	if (l<=s && t<=r) {
		tree[p].h=gh(c,t-s+1);
		tree[p].lzy=c;
		return;
	}
	pushdown(p);
	int mid=(s+t)/2;
	if (l<=mid) update(l,r,c,s,mid,lc);
	if (r>mid) update(l,r,c,mid+1,t,rc);
	pushup(p);
}
int query(int l,int r,int s,int t,int p) {
	if (l<=s && t<=r) return tree[p].h;
	pushdown(p);
	int mid=(s+t)/2;
	if (r<=mid) return query(l,r,s,mid,lc);
	if (l>mid) return query(l,r,mid+1,t,rc);
	return (query(l,r,s,mid,lc)*pw[min(r,t)-mid]%mod+query(l,r,mid+1,t,rc))%mod;
}
bool check(int l,int r,int d) {
	if (d==r-l+1) return true;
	return query(l,r-d,1,n,1)==query(l+d,r,1,n,1);
}
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>n>>m>>k>>(s+1),m+=k;
	init();
	build(1,n,1);
	while (m--) {
		int op,l,r,x;
		cin>>op>>l>>r>>x;
		if (op==1) update(l,r,x,1,n,1);
		else cout<<(check(l,r,x) ? "YES\n" : "NO\n");
	}
	return 0;
}
```
