## P13006 题解
[题目传送门](https://www.luogu.com.cn/problem/P13006)

## 思路
用 $a,b$ 字符串记录两个人名，$c$ 字符串记录 `is` 后的内容。

由于整句话中有空格还有一些对答案没有影响的字符，可以用一个字符串 $t$ 来“吞”掉这些字符。

注意，如果使用 `cin` 语句，那么最后一次 `cin` 会将 `.` 也输入进去，要改变判断条件。

## Code
```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
string a,b,c,t;
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>a>>t>>b>>t>>c;
	if (a==b && c=="weak.") cout<<"Plang.";
	else cout<<"Not plang.";
	return 0;
}
```
