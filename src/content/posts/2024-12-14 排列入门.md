## 定义

排列，permutation。

$ n $ 个元素中取 $ r $ 个按顺序排成一列，称为从 $ n $ 中取 $ r $ 的排列，其排列的方案数以 $ \mathrm {P}_n^r $ 表示.

例如从 $ (A,B,C) $ 中取 $ 2 $ 个为一组排列，可有 $ (A,B) , (A,C) , (B,A) , (B,C) , (C,A) , (C,B) $ 六个组，故 $ \mathrm {P}_3^2 = 6 $。

## 模型

从 $ n $ 个中取 $ r $ 个排列的典型模型是把 $ n $ 个有标志的球取 $ r $ 个放到 $ r $ 个有区别的盒子里。

## 定理

对于满足 $ rn $ 的正整数 $ n $ 和 $ r$，有

$$
\mathrm {P}_n^r = n \times (n - 1) \dots (n-r+1) = \dfrac{n!}{(n-r)!}
$$

例如：$ \mathrm {P}_5^3 = 5 \times 4 \times 3 = \dfrac{5!}{2!} $

全排列:  $ n! =1 \times 2 \times 3 \times \dots \times n $

特别：$ 0! = 1 $

## T1

将 $ a , b , c , d , e , f $ 进行排列，问:

### 第一问

排列有多少种?

---

$$
6! = 720
$$

### 第二问

使得字母 $ b $ 正好在字母 $ e $ 的左邻的排列有多少种？

---

捆绑法，将 $ b $ 和 $ e $ 看作一个整体，这样就有 $ 5 $ 个元素：$ {be, a, c, d, f} $。

$$
5! = 120
$$

### 第三问

使得字母 $ b $ 在字母 $ e $ 的左边的排列有多少种？

---

在所有排列中，$ b $ 和 $ e $ 的相对位置有两种情况：$ b $ 在 $ e $ 的左边，或者 $ e $ 在$ b $ 的左边。由于这两种情况是对称的，每种情况的数量是总排列数的一半。

$$
\dfrac{6!}{2} = \dfrac{720}{2} = 360
$$

## T2

“$ 15 $ 迷阵”由 $ 15 $个滑动方块组成，各方块分别标有数字 $ 1 $ 到 $ 15 $，并把它们摆放在如下图所示的 $ 4 \times 4 $方框内。该迷阵的挑战是从给定的初始位置把诸方块移动到任意指定的位置（这一挑战不是本问题要解决的课题）。这里的位置指的是在方框内这 $ 15 $ 个标有数字的方块的一种摆放方法，其中有一个方块是空的。本迷阵的方案总数是多少（不考虑是否有可能从初始位置移动到此位置）？

![image.png](https://nh.51goc.com/static/problemImage/18117/1626195163672.png/ "1626195163672.png")

---

空位可以在 $ 16 $ 个位置中的任何一个，因此有 $ 16 $ 种选择。

剩下的 $ 15 $ 个方块可以在剩下的 $ 15 $ 个位置上任意排列。

因此，排列的总数为：

$$
16 \times 15! = 16! = 20922789888000
$$

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
struct bign {
	int len,s[20005];
	bign() {
		memset(s,0,sizeof(s));
		len=1;
	}
	bign(int num) {
		*this=num;
	}
	bign(char *num) {
		*this=num;
	}
	bign operator =(int num) {
		char c[505];
		sprintf(c,"%lld",num);
		*this=c;
		return *this;
	}
	bign operator =(const char *num) {
		len=strlen(num);
		for (int i=0;i<len;i++)
			s[i]=num[len-1-i]-'0';
		return *this;
	}
	string str() {
		string res="";
		for (int i=0;i<len;i++)
			res=(char)(s[i]+'0')+res;
		return res;
	}
	void clean() {
		while (len>1 && !s[len-1])
			len--;
	}
	bign operator +(const bign &b) {
		bign c;    
		c.len=0;
		for (int i=0,g=0;g || i<len || i<b.len;i++) {
			int x=g;
			if (i<len) x+=s[i];
			if (i<b.len) x+=b.s[i];
			c.s[c.len++]=x%10,g=x/10;
		}
		return c;
	}
	bign operator -(const bign &b) {
		bign c;
		c.len=0;
		int x;     
		for (int i=0,g=0;i<len;i++) {
			x=s[i]-g;
			if (i<b.len) x-=b.s[i];
			if (x>=0) g=0;
			else {          
				x+=10;
				g=1;
			}
			c.s[c.len++]=x;
		}
		c.clean();
		return c;
	}
	bign operator *(const bign &b) {
		bign c;
		c.len=len+b.len;
		for (int i=0;i<len;i++)
			for (int j=0;j<b.len;j++)
				c.s[i+j]+=s[i]*b.s[j];
		for (int i=0;i<c.len-1;i++)
			c.s[i+1]+=c.s[i]/10,c.s[i]%=10;
		c.clean();
		return c;  
	}
	bool operator <(const bign &b) {
		if (len!=b.len) return len<b.len;
		for (int i=len-1;i>=0;i--)
			if (s[i]!=b.s[i]) return s[i]<b.s[i];
		return false;
	}
	bool operator >(const bign &b) {
		if (len!=b.len) return len>b.len;
		for (int i=len-1;i>=0;i--)
			if (s[i]!=b.s[i]) return s[i]>b.s[i];
		return false;
	}
	bign operator +=(const bign &b) {
		*this=*this+b;
		return *this;
	}
	bign operator -=(const bign &b) {
		*this=*this-b;
		return *this;
	} 
};
istream& operator >>(istream &in,bign &x) {
	string s;
	in>>s;
	x=s.c_str();
	return in;
}
ostream& operator <<(ostream &out,bign &x) {
	out<<x.str();
	return out;
}
int n;
bign ans=1;
signed main() {
	cin>>n;
	for (int i=1;i<=n;i++)
		ans=ans*i;
	cout<<ans;
	return 0;
}
```

## T4

前 $ N $ 个大写字母，后 $ M $ 个小写字母构成长度是 $ N+M $ 密码。要求字母都不相同。共有多少总不同的密码排列？

---

从 $ 26 $ 个大写字母中选择 $ N $ 个的组合数是 $ \binom{26}{N} $。

从 $ 26 $ 个小写字母中选择 $ M $ 个的组合数是 $ \binom{26}{M} $。

选择了 $ N $ 个大写字母和 $ M $ 个小写字母后，这 $ N+M $ 个字母的排列数是 $ (N+M)! $。

总的排列数为：

$$
\binom{26}{N} \times \binom{26}{M} \times (N+M)!
$$

## T5

如果所有同花色牌都放在一起，那么对于 $ 52 $ 张一副牌有多少种排序方法？

---

有 $ 4 $ 种花色，这 $ 4 $ 种花色可以有 $ 4! = 24 $ 种排列方式。

每种花色有 $ 13 $ 张牌，这 $ 13 $ 张牌可以有 $ 13! = 6227020800 $ 种排列方式。

将花色的排列方法和每种花色内部的排列方法相乘，得到总的排列方法：

$$
4! \times (13!)^4 = 36085481721713375974666734560870400000000
$$

```cpp
#include<bits/stdc++.h>
```

## T6

某星球上有 $ A $ 和 $ B $ 两个城堡要各派一个人组队参加比赛，已知 $ A $ 城堡的人数是 $ N $ 个 $ 12 $ 组成的数，$ B $ 城堡的人数是 $ M $ 个 $ 345 $ 组成的数。问有多少种可能的组队方案。

---

乘法原理，将 $ A $ 城堡的人数与 $ B $ 城堡的人数**相乘即可。

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
string add(string str1,string str2) {
	string str;
	int len1=str1.length();
	int len2=str2.length();
	if (len1<len2)
		for (int i=1;i<=len2-len1;i++)
			str1="0"+str1;
	else
		for (int i=1;i<=len1-len2;i++)
			str2="0"+str2;
	len1=str1.length();
	int cf=0,temp;
	for (int i=len1-1;i>=0;i--) {
		temp=str1[i]-'0'+str2[i]-'0'+cf;
		cf=temp/10;
		temp%=10;
		str=char(temp+'0')+str;
	}
	if(cf!=0) str=char(cf+'0')+str;
	return str;
}
string mul(string str1,string str2) {
	string str;
	int len1=str1.length(),len2=str2.length();
	string tempstr;
	for (int i=len2-1;i>=0;i--) {
		tempstr="";
		int temp=str2[i]-'0',t=0,cf=0;
		if (temp!=0) {
			for (int j=1;j<=len2-1-i;j++)
				tempstr+="0";
			for (int j=len1-1;j>=0;j--) {
				t=(temp*(str1[j]-'0')+cf)%10;
				cf=(temp*(str1[j]-'0')+cf)/10;
				tempstr=char(t+'0')+tempstr;
			}
			if (cf!=0) tempstr=char(cf+'0')+tempstr;
		}
		str=add(str,tempstr);
	}
	str.erase(0,str.find_first_not_of('0'));
	return str;
}
int n,m;
string s1,s2;
signed main() {
	ios::sync_with_stdio(!(cin.tie(0) && cout.tie(0)));
	cin>>n>>m;
	for (int i=1;i<=n;i++)
		s1+="12";
	for (int i=1;i<=m;i++)
		s2+="345";
	cout<<mul(s1,s2);
	return 0;
}
```
