## P1303 A*B Problem 题解
[题目传送门](https://www.luogu.com.cn/problem/P1303)

## 思路
这道题目要求我们计算两个非常大的非负整数的乘积。由于数字可能非常大，普通的整数类型无法直接存储和计算，所以我们需要使用高精度算法来处理。

高精度的核心思想就是模拟我们手工进行乘法计算的过程。

先将大数字以字符串形式存储，然后转换为数组，每个元素存储一位数字。

逐位相乘，从低位到高位，将第一个数的每一位与第二个数的每一位相乘。

将每一位的乘积结果累加到对应的位置上，并处理进位。

这里可以使用重载运算符，定义重载的运算符就像定义函数，只是函数的名字为 `operator` +重载的符号。比如重载 `+`，函数名就是 `operator +`。

示例：

## Code
```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
struct bign {
	int len,s[4005];
	bign() {
		memset(s,0,sizeof(s));
		len=1;
	}
	bign(int num) {
		*this=num;
	}
	bign(const char *num) {
		*this=num;
	}
	bign operator =(int num) {
		char c[20];
		sprintf(c,"%lld",num);
		*this=c;
		return *this;
	}
	bign operator =(const char *num) { //重载赋值运算符，注意倒序存储，方便计算
		len=strlen(num);
		for (int i=0;i<len;i++)
			s[i]=num[len-1-i]-'0';
		return *this;
	}
	string str() {
		string res="";
		for (int i=0;i<len;i++)
			res=(char)(s[i]+'0')+res; //倒序输出
		return res;
	}
	void clean() {
		while (len>1 && !s[len-1])
			len--;
	}
	bign operator *(const bign &b) { //重载乘号，高精度乘法
		bign c;
		c.len=len+b.len;
		for (int i=0;i<len;i++)
			for (int j=0;j<b.len;j++)
				c.s[i+j]+=s[i]*b.s[j];
		for (int i=0;i<c.len-1;i++)
			c.s[i+1]+=c.s[i]/10,c.s[i]%=10;
		c.clean(); //去除前导零
		return c;  
	}
};
//重载输入输出运算符，方便输入输出
istream& operator >>(istream &in,bign &x) {
	string s;
	in>>s;
	x=s.c_str();
	return in;
}
ostream& operator <<(ostream &out,bign &x) {
	out<<x.str();
	return out;
}
bign a,b;
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>a>>b;
	bign ans=a*b;
	cout<<ans;
	return 0;
}
```
