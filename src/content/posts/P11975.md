### P11975 [KTSC 2021] 翻牌游戏 / card 题解

[题目传送门](https://www.luogu.com.cn/problem/P11975)

## 思路

### 模类划分

每个格子 $(i, j)$ 属于模类 $(i \bmod M, j \bmod M)$。  

所有行操作（选行 $i$ 和 $k$）只会影响模类 $(i \bmod M, k)$ 中的格子；  

所有列操作（选列 $j$ 和 $k$）只会影响模类 $(k, j \bmod M)$ 中的格子。  

所以，每个模类内部的操作完全独立于其他模类。

那么整个问题就可以分解为 $M \times M$ 个子问题，每个子问题只关注一个模类是否能从全 `X` 变成目标图案中的对应部分。

### 可行性条件

对于每个模类 $(u, v)$，提取出所有满足 $i \equiv u \pmod{M}$ 且 $j \equiv v \pmod{M}$ 的格子，形成一个子矩阵。

由于每次操作只能对子矩阵的**整行或整列**进行翻转（异或 1），所以该子矩阵能被构造出来的条件是：

- 任取一行作为基准，其他每一行与基准行的异或结果必须是常数；
- 任取一列作为基准，其他每一列与基准列的异或结果也必须是常数。

换句话说，子矩阵中的每个元素 $a[i][j]$ 应能表示为 $r_i \oplus c_j$ 的形式（$r_i$ 为行偏移，$c_j$ 为列偏移）

### 实现

对每个模类 $(u, v)$：
1. 找到其中任意一个存在的行 $p_1$ 和列 $p_2$（若模类为空则跳过）；
2. 以第 $p_1$ 行为基准，检查每一行 $i$ 在所有 $j \equiv v \pmod{M}$ 列上与基准行的异或值是否一致；
3. 以第 $p_2$ 列为基准，检查每一列 $j$ 在所有 $i \equiv u \pmod{M}$ 行上与基准列的异或值是否一致；
4. 若任一模类不满足上述条件，直接返回 `false`。

若所有模类都满足，则返回 `true`。

## Code

```cpp line-numbers
#include<bits/stdc++.h>
using namespace std;
bool reversal(int n,int m,vector<string> a) {
	for (int u=0;u<m;u++)
		for (int v=0;v<m;v++) {
			int p1=-1,p2=-1;
			for (int i=u;i<n;i+=m) {
				p1=i;
				break;
			}
			for (int j=v;j<n;j+=m) {
				p2=j;
				break;
			}
			if (p1==-1 || p2==-1) continue;
			for (int i=u;i<n;i+=m) {
				int d=-1;
				for (int j=v;j<n;j+=m) {
					int cur=(a[i][j]=='O')^(a[p1][j]=='O');
					if (d==-1) d=cur;
					else if (d!=cur) return false;
				}
			}
			for (int j=v;j<n;j+=m) {
				int d=-1;
				for (int i=u;i<n;i+=m) {
					int cur=(a[i][j]=='O')^(a[i][p2]=='O');
					if (d==-1) d=cur;
					else if (d!=cur) return false;
				}
			}
		}
	return true;
}
```
