## 思路

首先我们先退化为一维（即所有点的 $y$ 相同），如果有三个点 $x_a<x_b<x_c$ 且我们需要从点 $a$ 到达点 $c$，最优的策略是什么呢？

::::info[策略]
如果直接从 $a$ 到 $c$ 连一条边的话，边权是 $(x_c-x_a)^2$ 的。我们展开一下：

$$
(x_c-x_a)^2 = (x_c-x_b+x_b-x_a)^2 = (x_c-x_b)^2+(x_b-x_a)^2+2(x_c-x_b)(x_b-x_a)
$$

显然连 $(a,b)$ 和 $(b,c)$ 是更优的。
::::

现在我们来推广一下，因为 $0 \le y \le 10$，所以整个平面上最多只有 $11$ 条直线。我们先考虑点 $a(x_a,y_a), b(x_b,y_b), c(x_c,y_c)$ 且 $y_a \not= y_b, y_b=y_c, x_b<x_c \le x_a$。你会发现结论是一样的，连 $(a,c)$ 和 $(c,b)$ 是更优的。

我们考虑该保留哪些边呢？容易发现，每一头奶牛只需要与左右相邻的奶牛和前面每条横线上离它最近的那头牛相连即可。

这样总边数就是 $11N$ 的，时间复杂度为 $O(11N \log (11N))$。

## Code

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
const int maxn=1e5+5;
struct node {
    int x,y;
}a[maxn];
bool cmp(node x,node y) {
    return x.x<y.x;
}
struct edge {
    int u,v,w;
    bool operator <(const edge &x) const {
        return w<x.w;
    }
};
int n,ans,id[15],fa[maxn];
vector<edge> e;
int find(int x) {
    return fa[x]==x ? x : fa[x]=find(fa[x]);
}
signed main() {
    ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
    cin>>n;
    for (int i=1;i<=n;i++)
        cin>>a[i].x>>a[i].y,fa[i]=i;
    sort(a+1,a+1+n,cmp);
    memset(id,-1,sizeof(id));
    for (int i=1;i<=n;i++) {
        for (int j=0;j<=10;j++)
            if (id[j]!=-1) {
                int u=id[j];
                int dx=a[i].x-a[u].x,dy=a[i].y-a[u].y;
                e.push_back({u,i,dx*dx+dy*dy});
            }
        id[a[i].y]=i;
    }
    sort(e.begin(),e.end());
    int cnt=0;
    for (auto [u,v,w]:e) {
        int fu=find(u),fv=find(v);
        if (fu==fv) continue;
        fa[fu]=fv;
        ans+=w;
        cnt++;
        if (cnt==n-1) break;
    }
    cout<<ans;
    return 0;
}
```
