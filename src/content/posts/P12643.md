### P12643 [KOI 2024 Round 1] 回收退货 题解

[题目传送门](https://www.luogu.com.cn/problem/P12643)

## 思路

dp。

令 $dp_{l,r,d}$ 表示已经回收了从第 $l$ 家到第 $r$ 家的所有物品，当前卡车停在左侧 $(d=0)$ 或右侧 $(d=1)$ 时的最短时间。

初始化：对于单个家庭 $i$，卡车到达 $X_i$ 的时间是 $X_i$。但如果 $T_i$ 较大，卡车必须等待到 $T_i$ 时刻才能回收物品。因此：

$$dp_{i,i,0} \gets dp_{i,i,1} \gets \max(X_i, T_i)$$

状态转移，需要考虑两种情况。

1. 从左侧扩展：

   - 如果当前在 $[l+1,r]$ 的左侧，则从 $X_{l+1}$ 移动到 $X_l$ 需要时间 $X_{l+1}-X_l$。

   - 如果当前在 $[l+1,r]$ 的右侧，则从 $X_r$ 移动到 $X_l$ 需要时间 $X_r-X_l$。

   - 动态转移方程为：
$$dp_{l,r,0} \gets \min(\max(dp_{l+1,r,0}+(X_{l+1}-X_l),T_l),\max(dp_{l+1,r,1}+(X_r-X_l),T_l))$$

2. 从右侧扩展：

   - 如果当前在 $[l,r-1]$ 的左侧，则从 $X_l$ 移动到 $X_r$ 需要时间 $X_r-X_l$。

   - 如果当前在 $[l,r-1]$ 的右侧，则从 $X_{r-1}$ 移动到 $X_r$ 需要时间 $X_r-X_{r-1}$。
  
   - 动态转移方程为：
$$dp_{l,r,1} \gets \min(\max(dp_{l,r-1,0}+(X_r-X_l),T_r),\max(dp_{l,r-1,1}+(X_r-X_{r-1}),T_r))$$
  
最终答案为 $\min(dp_{1,n,0}+X_1,dp_{1,n,1}+X_n)$。

## Code

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
const int inf=LLONG_MAX/2;
int n,X[3005],T[3005],dp[3005][3005][2];
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>n;
	for (int i=1;i<=n;i++)
		cin>>X[i];
	for (int i=1;i<=n;i++)
		cin>>T[i];
	//初始化
	for (int l=1;l<=n;l++)
		for (int r=l;r<=n;r++)
			dp[l][r][0]=dp[l][r][1]=inf;
	// 处理单个家庭的情况
	for (int i=1;i<=n;i++) {
		if (X[i]>=T[i]) dp[i][i][0]=dp[i][i][1]=X[i]; //到达时间足够
		else dp[i][i][0]=dp[i][i][1]=T[i]; //需要等待
	}
	for (int len=2;len<=n;len++)
		for (int l=1;l<=n-len+1;l++) {
			int r=l+len-1;
			//从左侧扩展
			int t1=dp[l+1][r][0]+(X[l+1]-X[l]); //从左邻家庭到达当前家庭的时间
			if (t1>=T[l]) dp[l][r][0]=min(dp[l][r][0],t1); //满足时间要求
			else dp[l][r][0]=min(dp[l][r][0],T[l]); //需要等待
			
			int t2=dp[l+1][r][1]+(X[r]-X[l]); //从右邻家庭到达当前家庭的时间
			if (t2>=T[l]) dp[l][r][0]=min(dp[l][r][0],t2);
			else dp[l][r][0]=min(dp[l][r][0],T[l]);
			
			//从右侧扩展
			int t3=dp[l][r-1][0]+(X[r]-X[l]); //从左邻家庭到达当前家庭的时间
			if (t3>=T[r]) dp[l][r][1]=min(dp[l][r][1],t3);
			else dp[l][r][1]=min(dp[l][r][1],T[r]);
			
			int t4=dp[l][r-1][1]+(X[r]-X[r-1]); //从右邻家庭到达当前家庭的时间
			if (t4>=T[r]) dp[l][r][1]=min(dp[l][r][1],t4);
			else dp[l][r][1]=min(dp[l][r][1],T[r]);
		}
	cout<<min(dp[1][n][0]+X[1],dp[1][n][1]+X[n]);
	return 0;
}
```
