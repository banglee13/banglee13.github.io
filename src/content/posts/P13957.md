### P13957 [ICPC 2023 Nanjing R] 背包 题解
[题目传送门](https://www.luogu.com.cn/problem/P13957)

## 思路
带免费获取机会的背包。

可以发现，最终带走的物品中，最优策略下，花费最高的 $k$ 件被选中的物品一定是免费获得的，不然就可以找到更优解。

那么我们可以枚举购买的宝石范围，将宝石按价格排序后，考虑前 $i$ 枚宝石用钱购买，后 $n−i$ 枚宝石中选择美丽度最高的 $k$ 枚免费获取。

## Code
```cpp line-numbers
#include<bits/stdc++.h>
using namespace std;
#define int long long
struct node {
    int w,v;  // w：价格，v：美丽度 
}a[5005];
bool cmp(node x,node y) {
    return x.w<y.w;
}
int n,W,k,ans,suf[5005],dp[5005][10005]; 
signed main() {
    ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
    cin>>n>>W>>k;
    for (int i=1;i<=n;i++)
        cin>>a[i].w>>a[i].v;
    sort(a+1,a+1+n,cmp);  // 按价格排序 
    // 预处理从第 i 枚到第 n 枚宝石中美丽度最高的 k 枚的总美丽度 
    for (int i=n;i>=1;i--) {
        vector<int> t;
        for (int j=i;j<=n;j++)
            t.push_back(a[j].v);
        sort(t.rbegin(),t.rend());
        suf[i]=0;
        for (int j=0;j<min(k,(int)t.size());j++)
            suf[i]+=t[j];
    }
    for (int i=1;i<=n;i++)
        for (int j=0;j<=W;j++) {
            dp[i][j]=dp[i-1][j];  //不选第 i 枚 
            if (j>=a[i].w)  //可以选第 i 枚 
                dp[i][j]=max(dp[i][j],dp[i-1][j-a[i].w]+a[i].v);
        }
    // 枚举分界点，前 i 枚用钱买，后 n-i 枚中选 k 个最漂亮的免费拿 
    for (int i=0;i<=n;i++)
        ans=max(ans,suf[i+1]+dp[i][W]);
    cout<<ans;
    return 0;
}
```
