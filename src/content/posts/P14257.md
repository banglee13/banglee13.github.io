## P14257 嫉妒（jealousy）题解
[题目传送门](https://www.luogu.com.cn/problem/P14257)

## 思路
对于某一场面试 $i$，如果想不被发现，必须同时满足：
1. 开始时间不被发现：$(i-1) \times s \ne y + j_1 \times t$ 对所有 $j_1 \ge 0$。
2. 结束时间不被发现：$i \times s \ne y + j_2 \times t$ 对所有 $j_2 \ge 0$。

由于小 Y 每隔 $t$ 分钟出现一次，从 $y$ 开始，所以小 S 会被小 Y 在第 $x$ 分钟发现而且仅当 $x \ge y$ 且 $(x-y) \bmod t=0$。

然后枚举每一场面试 $i$，只要有一场面试是合法的，那么就输出 `Yes`，否则输出 `No`。

时间复杂度为 $O(n)$。
## Code
```cpp line-numbers
#include<bits/stdc++.h>
using namespace std;
#define int long long
int n,y,s,t;
bool check(int x) {
	if (x<y) return false;
	return (x-y)%t==0; 
}
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>n>>y>>s>>t;
	for (int i=1;i<=n;i++)
		if (!check((i-1)*s) && !check(i*s)) {
			cout<<"Yes";
			return 0;
		}
	cout<<"No";
	return 0;
}
```
