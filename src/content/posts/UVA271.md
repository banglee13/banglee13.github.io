### UVA271 Simply Syntax 题解
[题目传送门](https://www.luogu.com.cn/problem/UVA271)

## 思路

考虑模拟。

注意到特殊字符都是前缀，所以考虑从右往左扫描。

用一个计数器来记录还需要多少个合法的句子来形成更大的句子。

在扫描的时候：
- 如果遇到小写字母 `p` 到 `z`，这是一个合法的句子，所以就不需要额外的句子来完成它。
- 如果遇到 `N`，是一个一元运算符，需要一个操作数。所以需要 $1$ 个句子来形成新的句子。
- 如果遇到 `C`、`D`、`E`、`I`，是二元运算符，需要两个操作数。所以需要 $2$ 个句子来形成新的句子。

处理完整个字符串后，如果有 $1$ 个计数，那么整个字符串是一个合法的句子；否则不合法。

## Code
```cpp line-numbers
#include<bits/stdc++.h>
using namespace std;
#define int long long
string s;
bool solve() {
	int cnt=0;
	for (int i=s.size()-1;i>=0;i--) {
		if (s[i]>='p' && s[i]<='z') cnt++;
		else if (s[i]=='N') {
			if (cnt<1) return false;
		}
		else if (s[i]=='C' || s[i]=='D' || s[i]=='E' || s[i]=='I') {
			if (cnt<2) return false;
			cnt--;
		}
		else return false;
	}
	return cnt==1;
}
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	while (cin>>s)
		cout<<(solve() ? "YES\n" : "NO\n");
	return 0;
}
```
