小测 T2。

## 思路

显然这个最终数组应该是由若干个负数作为前缀和若干个正数作为后缀组成的。那么必然存在一个分割点 $k$，使得 $a_1, a_2, \dots, a_k$ 最终都是负数，$a_{k+1}, a_{k+2}, \dots, a_n$ 最终都是正数。

对于这个正数后缀，要求 $a_i<a_{i+1}$，那么如果 $a_i \ge a_{i+1}$ 的话，就说明需要给后缀 $[i+1,n]$ 乘上一个很大的正整数才能使 $a$ 满足题目条件。

对于负数前缀，要求 $a_i<a_{i+1}$，即 $\lvert a_i \rvert > \lvert a_{i+1} \rvert$，那么如果 $a_i \le a_{i+1}$ 的话，就说明需要给前缀 $[1,i]$ 乘上一个很大的正整数才能使 $a$ 满足题目条件。

那我们便可以开两个数组表示前缀区间 $[1,i]$ 和后缀区间 $[i,n]$ 需要操作的数量就做完了。

注意初始的 $a_i$ 都是正数，需要乘上一次 $-1$ 才能转换为负数前缀。

## Code

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
const int maxn=2e5+5;
int T,a[maxn],pre[maxn],suf[maxn];
signed main() {
    ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
    cin>>T;
    while (T--) {
        int n;
        cin>>n;
        for (int i=1;i<=n;i++)
            cin>>a[i];
        for (int i=1;i<n;i++)
            pre[i]=pre[i-1]+(a[i]<=a[i+1]);
        suf[n]=0;
        for (int i=n-1;i>=1;i--)
            suf[i]=suf[i+1]+(a[i]>=a[i+1]);
        int ans=suf[1];
        for (int i=1;i<=n;i++)
            ans=min(ans,1+pre[i-1]+suf[i+1]);
        cout<<ans<<'\n';
    }
    return 0;
}
```
