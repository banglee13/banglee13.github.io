## 思路

考虑将排列分解为置换环。简单排列相当于只含 1-环 和 2-环 的排列，这两类无需操作。

对于长度为 $k>2$ 的环，每次操作可以将一个环一分为二，那么我们贪心地想，最优策略就是每次拆出一个 2-环，奇数环最后剩一个不动点：

- 当 $k$ 为偶数时，$\frac{k}{2}-1=\left\lfloor\frac{k-1}{2}\right\rfloor$ 次拆成 $\frac{k}{2}$ 个 2-环。
- 当 $k$ 为奇数时，$\frac{k-1}{2}=\left\lfloor\frac{k-1}{2}\right\rfloor$ 次拆成 $\frac{k-1}{2}$ 个 2-环和 $1$ 个不动点。

发现通式为 $\left\lfloor\frac{k-1}{2}\right\rfloor$，对所有环累加即为答案。

## Code

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
int T,a[1000005];
bool vis[1000005];
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>T;
	while (T--) {
		int n,ans=0;
		cin>>n;
		for (int i=1;i<=n;i++)
			cin>>a[i];
		memset(vis,false,sizeof(vis));
		for (int i=1;i<=n;i++)
			if (!vis[i]) {
				int cnt=0,cur=i;
				while (!vis[cur])
					cnt++,vis[cur]=true,cur=a[cur];
				if (cnt>2) ans+=(cnt-1)/2;
			}
		cout<<ans<<'\n';
	}
	return 0;
}
```
