### P1059 [NOIP 2006 普及组] 明明的随机数 题解
[题目传送门](https://www.luogu.com.cn/problem/P1059)

## 思路
可以使用 STL 中的 `std::set`，`set` 自带去重和排序，符合本题的要求。

`set` 的常用命令：
```
    begin();            // 返回指向第一个元素的迭代器
    end();              // 返回指向最后一个元素的后一个位置的迭代器
    clear();            // 清除所有元素
    count();            // 返回某个值元素的个数，用于判断 set 中是否有该元素
    size();             // 返回集合中元素的数目
    empty();            // 如果集合为空，返回 true，否则返回 false
    insert();           // 在集合中插入元素 
    erase();            // 删除集合中的元素
    find();            // 返回一个指向被查找到元素的迭代器
    max_size();         // 返回集合能容纳的元素的最大限值
    rbegin();           // 返回 set 反转后的开始指针(即原来的 end-1)
```

那么如何读取 `set` 中的元素呢？我们可以使用一个叫 `set<int>::iterator` 的正向迭代器来读取元素。

例如：
```cpp
set<int> s={1,2,3,4,5};
for (set<int>::iterator it=s.begin();it!=s.end();it++)
    cout<<*it<<" "; //输出：1 2 3 4 5
```

特别地，在 C++11 及以上的语言标准，可以使用范围 for 循环：
```cpp
for (int x:s)
    cout<<x<<" ";  //输出：1 2 3 4 5
```

对于每次输入，将输入的数字插入到 `set` 中，最后输出去重后的元素个数和排序后的元素即可。
## Code
```cpp line-numbers
#include<bits/stdc++.h>
using namespace std;
#define int long long
int n;
set<int> s;
signed main() {
    ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
    cin>>n;
    for (int i=1,x;i<=n;i++)
        cin>>x,s.insert(x);
    cout<<s.size()<<'\n';
    for (set<int>::iterator it=s.begin();it!=s.end();it++)
        cout<<*it<<" ";
    return 0;
}
```
