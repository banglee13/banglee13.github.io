## T1 星海的谐振
[P6278](https://www.luogu.com.cn/problem/P6278)
### Subtask 1
显然有 $O(n^3)$ 的暴力解法，枚举 $(i,k)$ 即可。

预期得分 20 pts。
### Subtask 2
将 $b$ 数组赋值后，就变成了一道求逆序对问题，可以用归并排序/树状数组/线段树求解，时间复杂度为 $O(N^2 \log n)$。

预期得分 50 pts。
### 正解
考虑每一秒新增的逆序对数。

发现第 $i$ 秒新增的逆序对数就是每个阈值为 $i−1$ 的前面在第 $i−1$ 秒时不稳定共鸣的数量。

发现这句话换一种方式说就是第 $i$ 个阈值对答案的贡献从第 $A_i$ 秒开始，并且贡献的大小为满足 $A_j>A_i(j<i)$ 的 $j$ 的个数。

发现这东西就是个逆序对，用树状数组维护即可。

时间复杂度为 $O(n \log n)$。

```cpp line-numbers
#include<bits/stdc++.h>
using namespace std;
#define int long long
const int maxn=1e5+5;
int n,ans,a[maxn],g[maxn],c[maxn];
int lowbit(int x) {
	return x&(-x);
}
void add(int x,int y) {
	for (int i=x;i<=n+2;i+=lowbit(i))
		c[i]+=y;
}
int sum(int x) {
	int res=0;
	for (int i=x;i>0;i-=lowbit(i))
		res+=c[i];
	return res;
}
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>n;
	for (int i=1;i<=n;i++)
		cin>>a[i];
	for (int i=1;i<=n;i++) {
		a[i]++;
		g[a[i]]+=(i-1)-sum(a[i]);
		add(a[i],1);
	}
	for (int i=1;i<=n;i++)
		cout<<ans<<'\n',ans+=g[i];
	return 0;
}
```

## T2 星尘碎片的共鸣
### Subtask 1
暴力，枚举每一对不同的星辰碎片即可，时间复杂度为 $O(n^2)$。

预期得分 20 pts。
### Subtask 2
观察到 $0 \le a_i < 2^{12}=4096$，下标计数然后遍历所有可能的能量值组合即可。

预期得分 30 pts。
### 正解
考虑按位拆分。

设 $f(j)$ 表示所有点对中，第 $j$ 位对总答案的贡献。

但 $\max$ 和 $\&$ 都不是线性的，难以直接拆位。

固定一个数 $a_i$，考虑所有 $a_j < a_i$ 的 $j$，此时 $\max(a_i, a_j) = a_i$。

所以可以先将数组排序，然后从左到右遍历，对于每个 $a_i$，只考虑它与前面比它小的数的组合（此时 $\max = a_i$）。

于是：
$$
\text{ans} = \sum_{i=1}^n \sum_{j<i} a_i \times (a_i \& a_j)
$$

交换求和顺序，按位处理：
$$
= \sum_{i=1}^n a_i \times \sum_{j<i} (a_i \& a_j)
= \sum_{i=1}^n a_i \times \sum_{j<i} \sum_{k=0}^{30} [a_i \text{ 和 } a_j \text{ 第 } k \text{ 位都为 } 1] \cdot 2^k
= \sum_{i=1}^n a_i \times \sum_{k=0}^{30} [a_i \text{ 第 } k \text{ 位为 } 1] \cdot (\text{前面第 } k \text{ 位为 } 1 \text{ 的数的个数}) \cdot 2^k
$$

用 $cnt_k$ 维护第 $k$ 位为 $1$ 的数的个数，遍历每个 $a_i$ 时，将其对答案的贡献累加，再更新 $cnt$ 数组。

时间复杂度为 $O(30n)$。

```cpp line-numbers
#include<bits/stdc++.h>
using namespace std;
#define int long long
const int mod=1e9+7;
int n,ans,a[100005],cnt[35]; // cnt[k]: 当前已遍历的数中，第 k 位为 1 的个数
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>n;
	for (int i=1;i<=n;i++)
		cin>>a[i];
	sort(a+1,a+1+n); // 排序，保证处理 a_i 时，前面的数都 <= a_i
	for (int i=1;i<=n;i++) {
		int x=a[i]%mod; // a[i] 对答案的乘数部分
		for (int j=0;j<=30;j++)
			if (a[i]&(1ll<<j)) // 如果 a[i] 的第 j 位为 1
				// 则它与前面所有第 j 位为 1 的数的 & 结果中，第 j 位贡献 2^j
				// 总贡献为 x * cnt[j] * (2^j)
				ans=(ans+x*cnt[j]%mod*(1ll<<j)%mod)%mod;
		// 更新 cnt 数组，将 a[i] 的每一位加入
		for (int j=0;j<=30;j++)
			if (a[i]&(1ll<<j)) cnt[j]++;
	}
	cout<<ans%mod;
	return 0;
}
```

## T3 山谷间的古老回响
[P7972](https://www.luogu.com.cn/problem/P7972)

### Subtask 1
显然可以用 dfs 枚举每一种合并情况，用一个 set 记录答案即可。

预期得分 20 pts。

```cpp line-numbers
#include<bits/stdc++.h>
#pragma GCC optimize(3)
using namespace std;
#define int long long
const int mod=1e9+7;
int qpow(int a,int b) {
	a%=mod;
	int res=1;
	while (b>0) {
		if (b&1) res=res*a%mod;
		a=a*a%mod,b>>=1;
	}
	return res;
}
string f(vector<int> a) {
	string s;
	for (auto x:a)
		s+=to_string(x);
	return s;
}
unordered_set<string> ans;
void dfs(vector<int> cur) {
	string s=f(cur);
	if (ans.count(s)) return;
	ans.insert(s);
	int n=cur.size()-1;
	if (n==1) return;
	for (int i=1;i<n;i++) {
		vector<int> t;
		t.push_back(0);
		for (int j=1;j<i;j++)
			t.push_back(cur[j]);
		t.push_back(min(cur[i],cur[i+1]));
		for (int j=i+2;j<=n;j++)
			t.push_back(cur[j]);
		dfs(t);
	}
}
int n;
bool flag=true;
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>n;
	vector<int> a(n+1);
	for (int i=1;i<=n;i++) {
		cin>>a[i];
		if (a[i]!=i) flag=false;
	}
	dfs(a);
	cout<<ans.size()%mod;
	return 0;
}
```
