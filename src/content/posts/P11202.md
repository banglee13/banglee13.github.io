## 思路

这个部分分非常有启发性啊。

::::success[当 $K=0$ 时]{open}
此时就是一个经典的 dp。

设 $dp[i][j]$ 表示已经匹配了 $S$ 的前 $i$ 个字符和 $T$ 的前 $j$ 个字符时的最短名字长度。

每一次的决策就是从 $S_{i+1}$ 和 $T_{j+1}$ 里挑一个字符作为下一个名字的字符。注意如果 $S_{i+1}=T_{j+1}$ 时，是可以同时匹配两者的。
::::

::::success[当 $K=1$ 时]
无非就是加多了一个限制，再开多一维 $0/1$ 记录是从 $S_i$ 还是 $T_j$ 转移过来的即可。
::::

我们沿着 $K=1$ 的思路继续推广。

::::success[正解]
我们发现一共是有 $52$ 个字母供我们填充，而 $K \le 3$，所以如果我们需要在两个字符中间来插入字符满足条件的话，是总能从这些字母里挑一个和前后都不冲突的字母，所以我们可以把这个看成一个通配符。

我们要知道对于一个新加入的字符需要补多少个通配符，我们只需要知道当前名字末尾最后 $K$ 个位置分别是什么字符即可。

对于末尾倒数第 $d$ 个字符，它只有 $4$ 种可能的情况：
1. 通配符；
2. 匹配了 $S$ 中的字符；
3. 匹配了 $T$ 中的字符；
4. 同时匹配了 $S$ 和 $T$ 中的字符。

如果我们知道了最后 $K$ 个位置进行了什么决策，那我们就可以还原出当前名字末尾 $K$ 个位置是什么字符。

这样我们就将状态数 $52^K$ 降到了 $4^K$。

所以我们定义 $dp[i][j][0 \sim 3][0 \sim 3][0 \sim 3]$ 表示已经匹配了 $S$ 的前 $i$ 个字符和 $T$ 的前 $j$ 个字符，末尾 $K$ 个位置分别进行哪个决策时的最短名字长度。

转移就简单了。
::::

实现细节较多。

## Code

```cpp
#include<bits/stdc++.h>
using namespace std;
#define int long long
const int maxn=505;
int n,m,k,dp[maxn][maxn][4][4][4]; //0 ? 1 s 2 t 3 s=t
string a,b;
void f(int i,int j,int cur,int k1,int k2,int k3,char c1,char c2,char c3,char c,int op) {
    int cnt=0;
    if (k>=1 && c1==c) cnt=k;
    else if (k>=2 && c2==c) cnt=k-1;
    else if (k>=3 && c3==c) cnt=k-2;
    int op1,op2,op3;
    if (cnt>=2) op1=op,op2=op3=0;
    else if (cnt==1) op1=op,op2=0,op3=k1;
    else op1=op,op2=k1,op3=k2;
    if (k<1) op1=0;
    if (k<2) op2=0;
    if (k<3) op3=0;
    dp[i][j][op1][op2][op3]=min(dp[i][j][op1][op2][op3],cur+cnt+1);
}
signed main() {
    ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
    // freopen("name.in","r",stdin);
    // freopen("name.out","w",stdout);
    cin>>n>>m>>k>>a>>b,a=" "+a,b=" "+b;
    int l1=(k>=1 ? 3 : 0),l2=(k>=2 ? 3 : 0),l3=(k>=3 ? 3 : 0);
    memset(dp,0x3f,sizeof(dp));
    dp[0][0][0][0][0]=0;
    for (int i=0;i<=n;i++)
        for (int j=0;j<=m;j++)
            for (int k1=0;k1<=l1;k1++)
                for (int k2=0;k2<=l2;k2++)
                    for (int k3=0;k3<=l3;k3++) {
                        int p1=i,p2=j;
                        const int d[4]={0,k1,k2,k3};
                        char c[4]={'?','?','?','?'};
                        for (int _=1;_<=k;_++) {
                            if (d[_]==1) c[_]=a[p1],p1--;
                            else if (d[_]==2) c[_]=b[p2],p2--;
                            else if (d[_]==3) c[_]=a[p1],p1--,p2--;
                        }
                        // s
                        if (i<n) f(i+1,j,dp[i][j][k1][k2][k3],k1,k2,k3,c[1],c[2],c[3],a[i+1],1);
                        // t
                        if (j<m) f(i,j+1,dp[i][j][k1][k2][k3],k1,k2,k3,c[1],c[2],c[3],b[j+1],2);
                        // s=t
                        if (i<n && j<m && a[i+1]==b[j+1]) f(i+1,j+1,dp[i][j][k1][k2][k3],k1,k2,k3,c[1],c[2],c[3],a[i+1],3);
                    }
    int ans=1e18;
    for (int k1=0;k1<=l1;k1++)
        for (int k2=0;k2<=l2;k2++)
            for (int k3=0;k3<=l3;k3++)
                ans=min(ans,dp[n][m][k1][k2][k3]);
    cout<<ans;
    return 0;
}
```
