### SP20985 UCBINTG - Archipelago 题解  
[题目传送门](https://www.luogu.com.cn/problem/SP20985)

## 思路
注意到 $1 \le R,C \le 50$，所以考虑模拟。

用一个数组标记当前的格子是否保留。

遍历每个格子，如果为陆地，那么就统计其四个方向中海洋的数量。如果数量大于等于 $3$，则该格子就会消失；否则保留。

在判断保留的同时，算出保留陆地的最小行、最大行、最小列和最大列，这样就能确定输出的位置了。

## Code
```cpp line-numbers
#include<bits/stdc++.h>
using namespace std;
#define int long long
// 四个方向：上、下、左、右
const int dx[]={-1,1,0,0},dy[]={0,0,-1,1};
int n,m;
char a[55][55];        // 原始地图
bool ans[55][55];      // 标记是否保留
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>n>>m;
	int minr=n,maxr=1,minc=m,maxc=1;
	for (int i=1;i<=n;i++)
		for (int j=1;j<=m;j++)
			cin>>a[i][j];
	// 遍历每个格子，判断是否保留
	for (int i=1;i<=n;i++)
		for (int j=1;j<=m;j++) {
			if (a[i][j]=='X') {
				int cnt=0; // 统计被海洋包围的边数
				// 检查四个方向
				for (int d=0;d<4;d++) {
					int nx=i+dx[d],ny=j+dy[d];
					if (nx<1 || nx>n || ny<1 || ny>m || a[nx][ny]=='.')  cnt++;
				}
				// 如果被淹没，则不保留
				if (cnt>=3) ans[i][j]=false;
				else {
					// 保留该陆地
					ans[i][j]=true;
					minr=min(minr,i);
					maxr=max(maxr,i);
					minc=min(minc,j);
					maxc=max(maxc,j);
				}
			}
			else ans[i][j]=false; // 原本是海洋，不保留
		}
	for (int i=minr;i<=maxr;i++) {
		for (int j=minc;j<=maxc;j++) {
			if (ans[i][j])  cout<<'X';
			else cout<<'.';
		}
		cout<<'\n';
	}
	return 0;
}
```
