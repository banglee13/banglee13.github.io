## P14197 [ICPC 2024 Hangzhou R] Kind of Bingo 题解
[题目传送门](https://www.luogu.com.cn/problem/P14197)

## 题目大意
有一个 $n \times m$ 的网格，格子编号从 $1$ 到 $n \times m$。给定一个长度为 $n \times m$ 的排列 $p$，按顺序执行操作：第 $i$ 次操作标记格子 $p_i$。

如果第 $b$ 次操作后，第一次出现至少有一行的所有格子都被标记，则称 $b$ 是该排列的 `bingo integer`。

现在可以进行最多 $k$ 次交换操作（每次交换排列中的两个元素），求能得到的最小 `bingo integer`。

## 思路
需要找到在最多进行 $k$ 次交换后，能够最早完成某一行标记的最小操作次数。

考虑二分答案。

二分查找最小的操作次数 $b$，使得存在至少一行可以通过最多 $k$ 次交换，在该操作次数前完成整行的标记。

对于每一个 $mid$，统计该行中有多少个格子原本在 $mid$ 次操作之后才被标记，如果这个数量不超过 $k$，说明可以通过交换把这些格子换到前面。只要有一行满足条件，$mid$ 就是可行的。

::::info[二分答案的正确性]
如果存在一行可以在 $mid$ 次操作内完成，那么所有大于 $mid$ 的值也都是可行的，答案具有单调性。
::::

::::warning[二分边界]
- 下界：$m$（至少需要标记 $m$ 个格子）
- 上界：$n \times m$（最坏情况需要标记所有格子）
::::

::::info[时间复杂度]
预处理 $O(n \times m)$，二分 $O(\log(n \times m) \times n \times m)$。
::::

## Code
```cpp line-numbers
#include<bits/stdc++.h>
using namespace std;
#define int long long
int T,n,m,k,p[100005];
bool check(int x) {
	for (int i=1;i<=n;i++) {
		int cnt=0;  //记录该行中位置超过x的格子数量
		for (int j=1;j<=m;j++) {
			int pos=(i-1)*m+j; //计算当前格子的编号
			if (p[pos]>x) cnt++;
		}
		// 如果超过x的格子数不超过k，可以通过交换完成
		if (cnt<=k) return true;
	}
	return false;
}
signed main() {
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	cin>>T;
	while (T--) {
		cin>>n>>m>>k;
		memset(p,0,sizeof(p)); //多测不清空，亲人两行泪
		for (int i=1,x;i<=n*m;i++)
			cin>>x,p[x]=i;
		int l=m-1,r=n*m+1;
		while (l+1<r) {
			int mid=(l+r)/2;
			if (check(mid)) r=mid;
			else l=mid;
		}
		cout<<r<<'\n';
	}
	return 0;
}
```
